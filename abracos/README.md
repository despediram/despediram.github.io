# Web Abraços 🐾

Site de abraços virtuais feito para amigos, familiares e qualquer pessoa querida — sem nomes obrigatórios e sem clima romântico.

## Link
https://despediram.github.io/abracos/

## O que tem
- Gatinho com **16 poses desenhadas** e animação em fases (caminha, se aproxima, estende as patinhas, abraça e volta)
- Quatro tipos de abraço: amizade, aconchego, força e comemoração
- Abraço coletivo, passeio do gatinho, recados, mensagem surpresa
- Cartão em PNG gerado no navegador para guardar ou enviar
- Personalização e compartilhamento por link; sem backend
- Som opcional, tema claro/escuro e contador local de abraços
- Suporte a celular e redução de movimento conforme preferência do dispositivo

## Arquivos
O site publicado é **index.html**: HTML, CSS, JS e sprite da animação incorporados para funcionar sem bibliotecas externas.
O pacote ZIP entregue ao autor inclui o código-fonte separado e as artes originais para manutenção.

## Privacidade
O contador fica apenas no dispositivo. Recados personalizados ficam no próprio URL, então não envie informações privadas.

## Para modificar
Atualize a página e faça commit em `abracos/index.html` na branch `main` do repositório GitHub Pages.
